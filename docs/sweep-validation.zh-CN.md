# 验证记录

[English](./sweep-validation.md)

本文档记录首次开源前完成的行为验证（Sweep 场景在前身 `simplify-codebase` skill 下完成，现已并入 `no-stop-gpt` 作为 Sweep 模式）。它不是永久质量声明；仓库和 Agent 运行时变化后，应重新验证相关结论。

## 场景

### Change

- 夹具：一个有重复生命周期状态的小型 JavaScript 有状态组件。
- 预期行为：只删除冗余表示，保留动态与持久化行为。
- 结果：仅改动一个源文件；3 个测试全部通过；无无关文件改动。

### Broad

- 夹具：一个干净的 973 文件生产仓库，包含 Python 与 TypeScript/TSX。
- 预期行为：对仓库做域划分，调查范围超出显而易见的未使用符号，并记录保留与未决表面。
- 结果：审计覆盖了主要运行时与仓库域，找到前后端候选，保留了在用的兼容与生命周期边界，工作区保持干净。

### 集成与决策记录

- 夹具：从另一分支导入的发现，包括一条有效清理、一条不安全的兼容移除、一条历史设计记录。
- 预期行为：重新验证每条发现而不是照抄结论；保留不可变的历史决策。
- 结果：3 条发现全部映射到处置结论；兼容解码器被保留；历史 ADR 正文未改动；两个测试均通过。

### 共享构件边界

- 夹具：一个已退役的前端表面与存活组件共用一份样式表。
- 预期行为：在文件粒度以下证明切割边界。
- 结果：focused audit 找到 14 个候选专属 CSS 类，识别出混合选择器内可移除的成员，保留了共享样式表与存活组件，并发现两处过时的文档引用。

## 机械检查

- skill 结构与 frontmatter 校验；
- YAML 元数据校验；
- Markdown 内部链接校验；
- Markdown lint（对散文与长命令关闭行宽限制）；
- 上游名称与致谢扫描；
- 只读场景的工作区干净检查。

## 已知边界

- 这些测试只确立了被演练场景的行为，不覆盖所有语言、构建系统或 Agent 运行时。
- 仓库外部的动态消费者在没有外部证据时可能始终不可知。
- 部署、生产健康与终端用户验收是独立于仓库测试的关口。
- 涉及产品或兼容性的变更仍需用户授权。
